# sql-study

## 프로젝트 소개
SQLite를 활용하여 기본 SQL 문법과 데이터베이스 구조를 학습한 실습 폴더입니다.  
테이블 생성부터 데이터 조회, 수정, 삭제까지 기본적인 데이터 처리 과정을 연습하였습니다.

## 학습 내용
- SQLite 테이블 생성
- 학생 정보 데이터 테이블 설계 및 데이터 입력
- SELECT, INSERT, UPDATE, DELETE 실습
- 테이블 JOIN 미션 수행

## 학습 목적
관계형 데이터베이스의 기본 구조를 이해하고  
SQL 질의를 활용한 데이터 처리 능력을 기초부터 다지기 위함입니다.
